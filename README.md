# Подвал Витриоля — прототип страницы

Страница Подвала с афишей: фонарь, спуск, шкаф, зал с синими огнями. Это прототип, чтобы посмотреть и обсудить:
вечера в афише выдуманы, запись на вечер никуда не отправляется.

Всё лежит в этой папке: `index.html`, пять картинок и шрифты в `fonts/`. Сборки и библиотек нет, страницу можно открыть
с любого хостинга для статических файлов.

Шрифты Forum и PT Sans распространяются по лицензии OFL.
