# Подвал Витриоля — прототип страницы

Страница Подвала с афишей: фонарь, темнота, шкаф, зал с синими огнями. Сцены меняются по нажатию на фонарь и на шкаф. Это прототип, чтобы посмотреть и обсудить:
вечера в афише выдуманы, запись на вечер никуда не отправляется.

Всё лежит в этой папке: `index.html`, четыре картинки и шрифты в `fonts/`. Сборки и библиотек нет, страницу можно открыть
с любого хостинга для статических файлов.

Шрифты Forum и PT Sans распространяются по лицензии OFL.
